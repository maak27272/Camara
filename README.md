# Mi Cámara

Panel web personal para conectar y supervisar una cámara IP.

Incluye Node.js + Express, panel web responsive, configuración por variables de entorno, base para RTSP/ONVIF y despliegue en Render.

## Inicio
1. Copia .env.example a .env.
2. Completa los datos de tu cámara.
3. Ejecuta npm install.
4. Ejecuta npm start.
